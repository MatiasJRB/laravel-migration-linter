# Security policy

## Supported versions

Only the latest released minor version receives security fixes while the package is pre-1.0.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository, or contact Matias through the email address published at [matiasjrb.com.ar](https://matiasjrb.com.ar).

Include reproduction steps, the affected version, and the expected impact. You should receive an acknowledgement within seven days.

## Scope

This package statically reads PHP source files. Reports may contain migration paths, table names, and snippets derived from operation names. Do not publish reports from private repositories without reviewing their contents.
